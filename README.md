# Smart Community

Smart Community is a real-time communication platform where users can chat, create communities, share files, and connect with others. It uses AI-powered moderation to detect toxic and abusive messages.

## Features
- Real-time messaging and group chats
- Communities and channels
- File sharing and notifications
- AI-powered content moderation

## Project Structure
- `frontend/` – User interface and website design.
- `backend/` – Server logic, APIs, and database operations.
- `ml/` – Machine learning models for toxic message detection.
- `docs/` – Project documentation.
